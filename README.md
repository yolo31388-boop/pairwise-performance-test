## 项目描述

## 已知问题

- 负载生成完全没做只能手动发请求
- 压力测试完全没做不知道服务器极限在哪里
- 延迟测试完全没做不知道响应时间是多少
- 吞吐量测试完全没做不知道每秒能处理多少请求
- 报告完全没做测试结果不能分享

## 运行测试

```bash
python -m pytest tests/test_performance_test.py -q
```

修复目标：所有 14 个测试全部通过。
